# AuriOpt AI Website v2

Responsive one-page static website built with HTML, CSS, and JavaScript.

## Preview
Extract this ZIP and open `index.html` in a browser. For a local server, open a terminal in this folder and run `python -m http.server 8000`, then visit `http://localhost:8000`.

## Before publishing
- Confirm `hello@auriopt.ai` receives email.
- Verify the service descriptions match work you are ready to deliver.
- Test desktop and mobile layouts.
- This site uses an email link, not a backend contact form.
- Add a privacy notice if analytics, cookies, or data-collection forms are added later.
- Keep this site in a separate repository from AuriOpt Select.

## Hosting
A static host such as GitHub Pages or Cloudflare Pages can host this site. Configure the custom domain in the hosting dashboard before changing DNS. Follow the host's official custom-domain documentation.
